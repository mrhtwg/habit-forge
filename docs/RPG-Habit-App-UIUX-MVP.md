## 1. MVP 范围定义

### 1.1 MVP 核心闭环

```
用户创建现实任务 → 完成任务获得 EXP/金币 → 角色升级 → 解锁外观/成就感 → 继续创建任务
```

**MVP 必须包含的功能**：

| 系统 | 功能 | 是否 MVP |
|------|------|---------|
| **任务管理** | 习惯（Habit）/ 每日（Daily）/ 待办（ToDo） | ✅ P0 |
| **角色系统** | 3D 角色展示 + 等级 + 属性条 | ✅ P0 |
| **奖励系统** | EXP / 金币 / 升级 | ✅ P0 |
| **基础商店** | 购买外观/装备（仅影响视觉） | ✅ P0 |
| **成就系统** | 里程碑徽章（轻量） | ✅ P1 |
| **数据看板** | 完成率统计 + 趋势图 | ✅ P1 |
| **用户系统** | 注册/登录/云同步 | ✅ P0 |

**MVP 明确砍掉的功能（v2.0+）**：

| 系统 | 原因 |
|------|------|
| ❌ 技能树 | 复杂度高，非核心循环 |
| ❌ 宠物系统 | 内容制作成本，非核心 |
| ❌ 公会系统 | 社交运维成本 |
| ❌ Boss 战 | 多人/限时逻辑复杂 |
| ❌ 好友系统 | 社交运维成本 |
| ❌ 装备属性系统 | 数值平衡复杂，MVP 仅外观 |
| ❌ 多语言 | 先做英文 |
| ❌ 暗黑模式 | MVP 仅暗色主题 |

### 1.2 MVP 与完整版对比

| 维度 | MVP（本文档） | 完整版（UIUX-Spec.md） |
|------|-------------|---------------------|
| **Tab 数量** | 4 个（Home / Quests / Forge / Profile） | 5 个 |
| **页面总数** | ~10 个 | ~30 个 |
| **3D 模型** | 3 职业 + 基础装备 | 5 职业 + Boss + 宠物 |
| **游戏系统** | 角色成长 + 商店 + 成就 | + 技能树/宠物/公会/Boss |
| **动画状态** | Idle / Victory / Hit | + Walk/Attack/Death/Skill |
| **开发工作量** | 约 6 个月 | 约 12 个月 |

## 2. 设计原则与系统

### 2.1 核心原则

| 原则 | MVP 落地 |
|------|---------|
| **即时反馈** | 任务完成 = 粒子动效 + 音效 + EXP 弹出 |
| **角色即锚点** | 主页持续展示 3D 角色，升级有专属动效 |
| **触觉优先** | 滑动手势完成任务，避免过多按钮 |
| **暗色沉浸** | 暗黑主题，让奖励的金色/绿色更突出 |
| **零学习成本** | 引导 4 步完成，首屏即核心操作 |

### 2.2 与 Habitica 的 MVP 级差异

| 维度 | Habitica MVP 时期 | HabitForge MVP |
|------|-----------------|---------------|
| 角色呈现 | 2D 像素静态图 | 3D GLB 可旋转 |
| 完成任务 | 点击复选框 | 左滑手势 + 粒子 |
| 升级反馈 | 顶部文字 | 全屏光效 + 角色动画 |
| 视觉 | 8-bit 复古 | 现代暗黑 + 霓虹 |

## 3. 3D 渲染方案（MVP 版）

### 3.1 方案：O3D（model-viewer WebView）

MVP 阶段直接使用 [O3D](https://pub.dev/packages/o3d) 包，理由与完整版一致（生产可用、GLB 完整支持、API 极简）。

**MVP 3D 使用场景（仅 2 处）**：

| 场景 | 模型 | 交互 | 动画 |
|------|------|------|------|
| **主页角色展示** | 用户角色（含装备外观） | 单指旋转 + 双指缩放 | Idle |
| **角色面板（全屏）** | 全屏角色 | 360° 旋转 | Idle / Victory |

**集成示例**：

```dart
final O3DController controller = O3DController();

O3D.asset(
  src: 'assets/glb/warrior_idle.glb',
  controller: controller,
  autoRotate: true,      // 缓慢自动旋转
  autoPlay: true,        // Idle 动画循环
)
```

**MVP 性能约束**：
- 角色 GLB < 1.5MB，三角面 < 6K
- 主页 WebView 预加载，页面切换不重建
- 角色面板退出时 `controller.pause()`

### 3.2 MVP 3D 资产获取

| 来源 | 费用 | MVP 适用性 |
|------|------|-----------|
| **Meshy.ai** | 免费额度 | 生成 3 职业角色 + 基础装备 |
| **Quaternius.com** | 免费 CC0 | 低面数 RPG 角色备选 |
| **GetGLB.com** | 免费 | 武器/装备模型 |

**MVP 关键交互**：

| 元素 | 手势 | 反馈 |
|------|------|------|
| **3D 角色** | 单指滑动 | 旋转角色 |

| 状态 | 视觉 |
|------|------|
| HP 满 | 绿色发光边框 |
| HP 低（<30%） | 红色闪烁 + 角色 Hit 动画 |
| HP 耗尽 | 角色倒地 + 红色遮罩 + 恢复提示 |
| 升级 | 全屏金色光效 + 角色 Victory 动画 |

## 7. 动效规格（MVP）

### 7.1 MVP 动效目录

| 动效 | 触发 | 时长 | 描述 |
|------|------|------|------|
| **Task Complete** | 左滑完成任务 | 400ms | 绿光 → ✓ 弹入 → 卡片上飘消失 |
| **Task Create** | 点创建按钮 | 300ms | 底部弹入表单 + 背景暗化 |
| **Level Up** | EXP 满 | 2000ms | 全屏金光 → 角色升空 → 数字跳动 |
| **HP Damage** | HP 降低 | 400ms | 屏幕红边 → HP 条收缩 → 角色闪白 |
| **HP Death** | HP=0 | 3000ms | 角色倒地 → 红色遮罩 → 恢复倒计时 |
| **Purchase** | 购买 | 500ms | 金币飞出 → 物品弹入背包 |
| **Equip** | 穿戴 | 400ms | 物品飞向角色 → 模型更新 |
| **Tab Switch** | 切 Tab | 250ms | 淡入 + 微上移 |
| **Push/Pop** | 导航 | 300/250ms | 右滑入 / 左滑回 |
| **Pull Refresh** | 下拉 | 循环 | 角色拉伸动画 |
| **Toast** | 通知 | 200/200ms | 顶部滑入 → 停留 → 上滑消失 |

### 7.2 缓动曲线（复用完整版）

```
Emphasized:  cubic-bezier(0.2, 0.0, 0, 1.0)
Bounce:      cubic-bezier(0.68, -0.55, 0.265, 1.55)
Spring:      SpringSimulation(damping: 0.7)
```

### 7.3 实现技术

| 类型 | Flutter 实现 |
|------|-------------|
| 补间 | `TweenAnimationBuilder` / `AnimatedContainer` |
| 序列 | `AnimationController` + `TweenSequence` |
| 粒子 | `CustomPaint` + `AnimationController` |
| 弹性 | `PhysicsSimulation` |
| 3D | O3D `controller.play()` |

## 9. 3D 角色资产规格（MVP）

### 9.1 GLB 文件规范

```

动画: Idle / Victory / Hit (仅 3 个)
```

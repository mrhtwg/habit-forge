# Roadmap

## Current Status

- [x] Flutter MVP core loop: tasks, character, forge, achievements
- [x] Go auth backend (Gin + GORM + PostgreSQL)
- [x] Monorepo layout: `app/`, `server/`, `proto/`, `docs/`

## Next Up

- [ ] Move core game logic from local Hive to Go backend
- [ ] Introduce Kratos + gRPC + shared proto contracts
- [ ] Cloud sync and multi-device support
- [ ] Unit/integration tests for backend business logic
- [ ] Flutter widget/integration tests
- [ ] CI pipeline (GitHub Actions)

## Later

- [ ] Vue 3 or React admin dashboard
- [ ] iOS release
- [ ] Theme/skin community system
- [ ] Public API for third-party integrations

## Non-Goals for MVP

- Pets, guilds, boss raids, and complex social systems
- Real-money purchases
- Full skill trees

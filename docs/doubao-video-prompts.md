# HabitForge · 豆包视频生成提示词（按角色）

> 用途：在豆包生成 3 职业 × 4 状态动画视频，用于 App 内 `video_player` 播放或拆帧转 Sprite Sheet。
>
> 关键：**每个角色 4 个提示词共用同一套视觉描述**，只改动作/状态词，确保角色外观在所有状态下视觉一致。

---

## 视频处理流程

```
豆包生成 MP4 → 可选方案：
  ├── video_player 直接播（最简单，MP4≈500KB-2MB/个）
  ├── 拆帧 → 拼 GIF（支持透明需处理背景键控）
  ├── 导入 AE → Auto Trace → Bodymovin → Lottie（矢量，文件小）
  └── 拆帧 → Sprite Sheet → 自定义播放器
```

## 批量生产顺序

| 批次 | 内容 | 数量 | 用途 |
|------|------|------|------|
| **P0** | 3 角色 × (Idle + Victory) | 6 个视频 | 主页展示 + 升级反馈 |
| **P1** | 3 角色 × (Hit + Death) | 6 个视频 | 扣血 + 死亡动画 |
| **P2** | Warrior × Attack | 1 个视频 | Boss 战原型测试 |

**建议：先用 Warrior 全流程测试一次。** 生 Warrior × Idle → 确认风格满意 → 继续生 Warrior × Victory/Hit/Death → 确认 4 个状态外观一致 → 再批量做 Mage 和 Ranger。

# HabitForge · 豆包 UI 界面生成提示词

> 目标：用豆包生成所有页面的 UI 设计图，作为 Flutter 开发的视觉参考。
> 风格：**暗黑奇幻 RPG 主题、紫金配色、现代移动端原生感、简洁信息层级**。
> 用途：豆包出图 → 截图放入 Figma 作为 reference → 按图写 Flutter UI 代码。

---

## 全局设计系统（每个提示词都需要包含此段）

```
移动应用界面设计，暗黑奇幻RPG风格，紫金配色，
主色 #6C5CE7（深紫）、辅色 #FFD700（金色）、
高亮 #00E676（翠绿·正面反馈）、危险 #FF5252（红色·负面反馈）、
背景色 #0D0D1A（极深暗蓝）、卡片色 #1A1A2E、
字体白色 #FFFFFF、次要文字 #B8B8D4、
所有卡片圆角 12px、按钮圆角 8px、图标风格为 Phosphor Icons 线性风格、
字体使用 Cinzel（标题）+ Inter（正文）+ JetBrains Mono（数字）、
iPhone 15 Pro 尺寸 393×852，无刘海/灵动岛遮挡，
阴影柔和，不要过度设计，信息层级清晰，
不要展示任何中文、所有文字必须英文，
底部标签栏 4 个图标：首页/任务/商店/我的
```

## 生成顺序建议

| 优先级 | 页面 | 数量 | 理由 |
|--------|------|------|------|
| **P0** | Home 主页 | 1 张 | 核心页面，其他页面与之风格统一 |
| **P0** | Quests 任务页 | 1 张 | 用户最常用的操作页 |
| **P0** | Task Form 创建弹窗 | 1 张 | 高频操作 |
| **P1** | Splash + Auth | 2 张 | 用户首次接触 |
| **P1** | Onboarding 4步 | 4 张 | 首次体验关键 |
| **P1** | Forge 商店 | 1 张 | 核心变现页 |
| **P2** | Character 角色面板 | 1 张 | 次常用 |
| **P2** | Profile 个人页 | 1 张 | 次常用 |
| **P2** | Reward 弹窗（3种状态） | 3 张 | 反馈体验 |
| **P3** | Statistics / Achievements | 2 张 | 数据查看 |
| **P3** | Settings | 1 张 | 低频 |
| **P3** | 边界状态（Empty/Loading/Error/Help） | 4 张 | 完整性 |

**建议：** 先生成 P0 的 3 张（Home/Quests/TaskForm） → 确认风格满意 → 再批量生成其余。

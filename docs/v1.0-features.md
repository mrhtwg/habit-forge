# HabitForge V1.0 Feature Overview

## About

HabitForge V1.0 is a **local-first RPG-style habit tracker** built with Flutter. It turns real-life tasks into a character growth loop: complete tasks, earn EXP and gold, level up your hero, and spend rewards in the Forge.

The V1.0 release includes:

- A full Flutter mobile client with task, character, shop, achievement, and statistics systems.
- Two runtime data modes: **Hive** (local, default) and **Firebase** (cloud).
- No server component: the MVP ships without a self-hosted backend.

---

## Task Management

- Three task types:
  - **Habit** — repeated positive or negative behaviors.
  - **Daily** — tasks with weekday repeat schedules.
  - **ToDo** — one-time tasks with due dates.
- Difficulty levels: **Easy**, **Medium**, **Hard** — affect EXP and gold rewards.
- Tags and priority for organization and filtering.
- Streak tracking to reward consistency.
- HP penalties for skipped or overdue tasks.
- Swipe actions: complete, postpone, skip, and delete.
- Task creation through a bottom-sheet form.

---

## Character Progression

- Choose a class during onboarding:
  - **Warrior**
  - **Mage**
  - **Ranger**
- Each class has its own idle animation sequence.
- Complete tasks to earn:
  - **EXP** — progresses toward the next level.
  - **Gold** — the in-app currency for the Forge.
- Rewards scale with difficulty and streak multiplier (up to ×2.0).
- Level system up to **max level 50** with a progressive EXP curve.
- Stat points awarded on level-up; spend them on:
  - STR / INT / AGI / DEF / VIT / LUK
  - Effects: **INT** +1% EXP per point, **STR** +1% gold per point, **VIT** +2 HP cap per point, **DEF** −1 HP damage per point (min 1); AGI / LUK effects pending
- HP system:
  - Lost HP for missed or skipped tasks.
  - At 0 HP, the character enters a defeated state.
  - Recovery restores partial HP after **30 minutes**.

## Forge & Economy

- Shop with items categorized by rarity.
- Prices use **gold**, with **gems** as a premium currency.
- **Daily Deal** — a rotating discounted item with an expiry timestamp.
- Purchased items persist in the player's inventory.
- Equipment slots:
  - Weapon
  - Helmet
  - Armor
  - Accessory
- Equipping items updates the character page.

## Achievements & Statistics

- Achievement system with unlock thresholds and gem rewards.
- Statistics page with:
  - Time-segment bar charts.
  - Streak leaderboards.
  - Completion trends.
- Profile page with quick access to character, achievements, statistics, and settings.

## Onboarding & Authentication

- 4-step onboarding:
  1. Welcome
  2. Choose Class
  3. Create First Habit
  4. Ready
- Two runtime modes:

| Mode | Data Storage | Auth |
|---|---|---|
| Hive | Local on-device | Guest / local |
| Firebase | Firebase cloud | Google Sign-In |

- Hive mode is the default and requires no account, network, or Firebase configuration.
- Firebase mode enables cloud-backed auth and data; gameplay stays local-first until the user signs in.

## Data & Sync

V1.0 has **no server component**. All game state is stored and computed on the device:

- **Hive** — the default mode; every task, character, shop, and achievement record lives in a Hive box on-device.
- **Firebase** — optional cloud sync; Firebase Auth (Google Sign-In) plus Firestore keep per-user documents, while gameplay continues to work offline against the local cache.

A self-hosted backend is not part of this release. The protobuf contracts in `proto/` describe the data shapes the client uses, and the Dart models under `app/lib/generated/protos/` are generated from them.

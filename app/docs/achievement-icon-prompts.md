# Achievement Icon Generation Prompts

## Common Style

Every numbered entry below is a complete copy-ready prompt. The common visual constraints are included in each entry, so paste one numbered line directly into your image-generation platform.

> square 1:1 game achievement icon, casual fantasy RPG mobile game, polished premium 2D illustration, one single hero object only, bold readable silhouette, centered composition, generous clean negative space, soft gold rim light, rich but controlled colors, transparent background, no text, no letters, no numbers, no UI, no watermark, milestone tier expressed through material quality and aura intensity rather than literal quantity

Recommended output: `1024x1024` PNG with transparent background.

## Embedded Negative Constraints

The following constraints apply to every prompt: photorealistic, 3D render, realistic human, character face, full scene, landscape, background, text, letters, numbers, logo, watermark, UI screenshot, blurry, low resolution, cropped object, multiple unrelated objects, multiple copies of the same object, collections, piles, grids, repeated badges, repeated stars, tiny decorative icons, clutter, excessive empty space.

## Quality Rules

- Always generate one recognizable main subject, not a scene or collection.
- Never visualize the achievement threshold as a literal count. For example, `tasks_500` should be a more legendary trophy, not 500 tiny symbols.
- Use one large emblem, one piece of equipment, one chest, one flame, or one creature as the focal point.
- Use a clean silhouette and large color areas so the icon remains readable at 64px.
- Prefer subtle glow, engraved details, a single gemstone, or a simple aura to communicate rarity.
- Avoid tiny stars, floating objects, repeated symbols, piles of items, complicated backgrounds, and visual noise.

> Note: The numbered descriptions are the subject concepts. When copying one entry, prepend the Common Style block and append the Embedded Negative Constraints block if your platform does not preserve the document instructions.

# Achievement Icon Generation

The source atlas in `assets/images/achievements/base/achievement_atlas.png` was generated with the built-in image tool.
It provides five cohesive visual families used by the 130 achievement milestones.

## Final Prompt

```text
Use case: stylized-concept
Asset type: mobile RPG achievement icon set reference
Primary request: five separate polished fantasy achievement emblems arranged in one clean row: golden quest scroll with checkmark, magical orange streak flame, radiant hero level star, treasure chest with forge hammer, phoenix feather rising from a cracked heart shield
Style/medium: premium casual mobile game icons, soft 3D painted illustration, chunky readable silhouettes, consistent art direction
Composition/framing: five isolated centered emblems with generous spacing, transparent background
Color palette: cheerful gold, orange, sky blue, emerald, crimson, each with dark purple outline
Constraints: exactly five emblems, transparent background, no text, no letters, no numbers, no watermark, no UI frames
```

The atlas was cropped into category masters and copied to stable achievement-specific filenames. The card color, progress,
threshold, lock treatment, and reward make each milestone distinct while preserving one art direction.

# Complete Achievement Icon Prompts

每一条都是完整提示词，可单独复制给第三方 AI。请不要把多条合并发送。所有图标必须遵循 HabitForge 当前 App UI 主题：明亮可爱的卡通 RPG、紫色主色、奶油白卡片、金色描边、圆润造型、柔和阴影。

## HabitForge UI Theme

每个图标都必须像是直接属于 HabitForge 成就页面的 UI 组件，而不是写实奇幻插画：

- cartoon casual RPG mobile UI asset
- rounded chunky shapes, friendly playful proportions
- HabitForge purple `#7658D8` and dark purple outlines
- warm cream `#F4EFE2` card-compatible highlights
- golden yellow `#FFD166` achievement accents
- sky blue `#8FD4FF` secondary highlights
- clean 2D vector-like illustration, soft subtle drop shadow
- centered single badge, readable at 64px, transparent background
- no realistic texture, no dark horror mood, no complex scenery

## Category Visual System

同一大类必须使用同一个基础轮廓，只通过材质、颜色、光效和稀有度变化表达等级。不要在同一类别中切换成不同物件。

| Category | Fixed base silhouette | Allowed progression changes | Forbidden substitutions |
| --- | --- | --- | --- |
| Task achievements | One rolled quest scroll with one central seal | parchment color, seal gemstone, ribbon color, glow strength, engraving complexity | compass, notebook, trophy, castle, dragon, pile of scrolls |
| Streak achievements | One single magical flame inside a simple flame-shaped aura | flame color, core gemstone, aura intensity, flame tip shape | calendar, torch, phoenix, dragon, campfire, multiple flames |
| Level achievements | One rounded hero shield with one central gemstone | shield material, gem color, rim glow, engraved emblem complexity | sword, helmet, crown, armor set, wings, multiple equipment pieces |
| Purchase achievements | One rounded treasure chest with one central lock | wood or metal material, lock gemstone, trim color, glow strength | shop stall, shopping bag, cabinet, merchant, multiple items |
| Recovery achievement | One phoenix silhouette rising from one small ash base | wing color, heart gemstone, flame aura, feather detail | skull, tombstone, battlefield, multiple birds, horror imagery |

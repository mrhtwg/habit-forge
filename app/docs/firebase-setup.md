# Firebase Configuration

## You need to replace all values below with your real Firebase project values.

### Step 1: Get values from Firebase Console

1. Go to https://console.firebase.google.com
2. Select your project
3. Project Settings → General → Your apps → Add app → Android
4. Package name: `com.habitforge.habitforge`
5. SHA-1: `D7:E5:F3:3F:A2:16:04:13:AC:8B:EA:0E:8A:58:C9:9F:9D:27:9C:75`
6. Download `google-services.json`
7. Replace `android/app/google-services.json` with it

### Step 2: Update firebase_options.dart

Copy the following values from Firebase Console → Project Settings → General:

- `apiKey` → Web API Key
- `appId` → from downloaded google-services.json → client[0].client_info.mobilesdk_app_id
- `messagingSenderId` → Project number
- `projectId` → Project ID
- `storageBucket` → `<project-id>.appspot.com`

### Step 3: Google Sign-In

For Google Sign-In to work on Android:

- Add SHA-1 `D7:E5:F3:3F:A2:16:04:13:AC:8B:EA:0E:8A:58:C9:9F:9D:27:9C:75` in Firebase Console → Authentication → Sign-in method → Google

### Step 4: iOS — Add app in Firebase Console

1. Firebase Console → Project Settings → Add app → iOS
2. Bundle ID: `com.habitforge.habitforge`
3. Download `GoogleService-Info.plist` → replace `ios/Runner/GoogleService-Info.plist`
4. Copy the values from the plist into `lib/firebase_options.dart` (uncomment the `ios` config)
5. Enable Google Sign-In: in plist, find `REVERSED_CLIENT_ID` (not in template — generated by Firebase) — this is needed for Google auth

**If you haven't registered iOS app yet:** The current `firebase_options.dart` returns Android config for all platforms. iOS will work after you:

1. Register iOS app in Firebase Console
2. Copy values into `firebase_options.dart`
3. Run `flutter pub get` + `cd ios && pod install --repo-update`
